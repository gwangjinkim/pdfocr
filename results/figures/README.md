# Fraktur boundary evidence

Unmodified boundary crops from Christoph Wilhelm Hufeland, *Makrobiotik*, 1826,
Archive.org item [makrobiotikoderd00hufeuoft](https://archive.org/details/makrobiotikoderd00hufeuoft), PDF pages 34–35.

The crops are the exact 400-DPI native-pdfrune inputs used by both visual readers.
Their hashes are recorded in the reader-comparison JSON. The code license does
not claim ownership of the historical source material or relicense Archive.org
scans. Complete book PDFs and model weights are downloaded separately.
